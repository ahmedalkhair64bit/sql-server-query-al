## Upgrade

Back up and preserve the existing data volume and its matching `APP_SECRET`.
Do not generate a replacement secret or run `docker compose down -v` during an
upgrade. Additional accounts require `ALLOW_SIGNUP=1`. Once the image is
published and verified, use the updated Compose pin to pull and replace the
container while retaining its environment and volume.

## Build, test and publish

Run from the reviewed `release/docker-20260930` branch or its exact commit,
with Node.js 24.10+, Docker and a Docker Hub account allowed to push to `worlber`.
Do not build from an older `main` checkout that lacks the merged changes.

```bash
set -euo pipefail

git clone --branch release/docker-20260930 https://github.com/ahmedalkhair64bit/sql-server-query-al.git
cd sql-server-query-al
git rev-parse HEAD

npm ci
npm test
npm run lint
npx tsc --noEmit
npm run verify:parser

docker build --pull --platform linux/amd64 -t sql-server-query-al:20260930 .
npm run stress:api -- --docker sql-server-query-al:20260930

docker tag sql-server-query-al:20260930 worlber/sql-server-query-al:20260930
docker login --username YOUR_DOCKERHUB_USERNAME
docker push worlber/sql-server-query-al:20260930

docker buildx imagetools inspect worlber/sql-server-query-al:20260930
docker pull --platform linux/amd64 worlber/sql-server-query-al:20260930
docker image inspect --format '{{json .RepoDigests}}' worlber/sql-server-query-al:20260930
npm run stress:api -- --docker worlber/sql-server-query-al:20260930
```

Stop on any failed check. Record the source commit, pushed digest and pulled
digest, and confirm the digest matches and the pulled image passes the stress
suite before marking this release published. The stress suite uses controlled
providers and disposable data; it does not use an existing installation.

The existing GitHub workflow publishes `latest` and the commit-SHA tag on pushes
to `main`. It does **not** publish `20260930`; the commands above publish that
tag. Keep the release PR in draft until the dated image is verified, then update
the publication status in this file and README before merging.
